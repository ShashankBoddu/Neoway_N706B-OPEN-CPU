================================================================================
NEOWAY N706B OPENCPU SDK DEMO GUIDE
================================================================================
This document catalogs and explains every single source file, header file, and
function within the Neoway N706B OpenCPU SDK test demos.
--------------------------------------------------------------------------------
1. NWY_TEST_CLI - COMMON HELPER FILES (nwy_test_cli/comm/)
--------------------------------------------------------------------------------
These files establish the CLI terminal menu, command parsing, and input/output interfaces.
### 1. nwy_test_cli_adpt.c / nwy_test_cli_adpt.h
* **Purpose**: Communication adapter layer between the OpenCPU task queue and the serial interface (UART/USB).
* **Functions**:
* `nwy_test_cli_input_gets(const char *prompt)`: Blocks and prompts the user on the serial console, returning the inputted line string.
* `nwy_test_cli_echo(const char *fmt, ...)`: Thread-safe, formatted printing wrapper that outputs text directly to the active serial interface.
### 2. nwy_test_cli_menu.c
* **Purpose**: Implements the main interactive terminal menu. It maps typed numbers/commands to corresponding testing functions.
* **Functions**:
* `nwy_test_cli_menu_show()`: Prints the hierarchical list of testing options (SIM, Network, OS, PM, TCP/IP, SMS, drivers, etc.).
* `nwy_test_cli_menu_parse(char *cmd)`: Compares user console inputs and routes execution to the registered test modules.
### 3. nwy_test_cli_utils.c / nwy_test_cli_utils.h
* **Purpose**: General utility helpers for CLI console operations, including text formatting, string conversion, and argument checking.
* **Functions**:
* `nwy_test_cli_hex_to_bin(const char *hex, uint8_t *bin, int max_len)`: Parses hex strings into raw binary buffers.
* `nwy_test_cli_bin_to_hex(const uint8_t *bin, int len, char *hex_out)`: Converts raw binary buffers back into readable hexadecimal string representation.
--------------------------------------------------------------------------------
2. NWY_TEST_CLI - MODULE IMPLEMENTATIONS (nwy_test_cli/modules/)
--------------------------------------------------------------------------------
These files contain interactive test functions that invoke the actual Neoway OpenCPU APIs.
### 1. nwy_test_cli_network.c
* **Purpose**: Cellular registration, CSQ, network mode setting, and operator details interface testing.
* **Functions**:
* `NwyErrorToString(nwy_error_e code)`: Translates SDK network error codes into human-readable strings.
* `nwy_test_cli_nw_get_mode()`: Prompts for `sim_id` and queries the active network mode (Auto, GSM, LTE).
* `nwy_test_cli_nw_set_mode()`: Configures the radio network mode for the selected SIM slot.
* `nwy_test_cli_nw_get_priband()`: Gets the active primary RF band configurations for a selected RAT.
* `nwy_test_cli_nw_set_priband()`: Sets or locks specific RF bands for GSM or LTE.
* `nwy_test_cli_nw_get_ims_mode()`: Queries IMS/VoLTE status (enabled/disabled) on the modem.
* `nwy_test_cli_nw_set_ims_mode()`: Enables or disables VoLTE functionality.
* `nwy_test_cli_nw_get_radio_mode()`: Queries standard radio power states (normal, flight mode, low power).
* `nwy_test_cli_nw_set_radio_mode()`: Puts the RF module into flight mode or normal mode.
* `nwy_test_cli_nw_get_edrx_info()` / `nwy_test_cli_nw_set_edrx_info()`: Queries or configures eDRX low-power settings (not supported on all platforms).
* `nwy_test_cli_nw_get_psm_info()`: Queries Power Saving Mode (PSM) settings, including T3412 and T3324 timers.
* `nwy_test_cli_nw_set_psm_info()`: Sets Power Saving Mode active states and requested timers.
* `nwy_test_cli_nw_get_custom_cfg()`: Queries customized modem features (e.g. netauto, uemode, dataonly, bandcap, NITZ).
* `nwy_test_cli_nw_set_custom_cfg()`: Writes changes to custom configs.
* `nwy_test_cli_nw_get_oper_info()`: Queries MCC, MNC, EONS (Operator name), and SPN values.
* `nwy_test_cli_nw_get_csq()`: Queries CSQ level (0-31, 99) and bit error rate.
* `nwy_test_cli_nw_get_signal_info()`: Returns detailed network signal info (RSCP, RSRP, RSRQ, RSSI, SINR) depending on the active RAT.
* `nwy_test_cli_nw_reg_info()`: Prints detailed PS/CS registration states and rejection causes.
* `nwy_test_cli_nw_get_cellinfo()`: Scan and retrieve information for serving cell and neighboring cells (earfcn, cellid, rsrp, etc.).

3. NWY_FUNCTION_DEMO - SOURCE FILES (nwy_function_demo/src/)
--------------------------------------------------------------------------------
Standalone demo loops showing how to construct a robust, production-ready OpenCPU app.
### 1. nwy_demo_entry.c
* **Purpose**: Initial bootstrap launcher of the OpenCPU app.
* **Functions**:
* `nwy_demo_init()`: Configures the virtual AT command engine mutex.
* `nwy_open_app_entry()` / `appimg_enter()`: Entry hook. Spawns `nwy_main_control` and `nwy_net_monitor` threads.
* `appimg_exit()`: Application shutdown handler.
### 2. nwy_demo_main_control.c
* **Purpose**: Primary event-handling dispatcher thread.
* **Functions**:
* `nwy_main_control_func(void *param)`: Loops indefinitely on thread event queues. Dispatches incoming `NWY_MAIN_DATA_CALL_CHANGE_MSG` events.
* `nwy_main_data_call_change_proc(int profile_id, nwy_data_call_state_e state)`: Triggers the TCP client application (`nwy_tcp_cli_demo_main`) when network connectivity is confirmed.
### 3. nwy_demo_network_monitor.c
* **Purpose**: Core background worker that checks signal quality and cellular status.
* **Functions**:
* `nwy_demo_sim_err_proc()` / `nwy_demo_reg_err_proc()`: SIM / Reg error hooks.
* `nwy_demo_data_call_monitor_cb()`: Callback for connection validation.
* `nwy_demo_cfun_start()`: Asserts full cellular state (`AT+CFUN=1`).
* `nwy_demo_cfun_reset_ckeck(int reset_flag)`: Power-cycles RF and data states.
* `nwy_demo_restart_data_call()`: Posts connection restart message.
* `nwy_demo_data_call_check()`: Loops until SIM and registration are fully validated.
* `nwy_demo_check_cfun_reset()`: Checks signal (CSQ) and registration. Triggers AT command restarts (`AT+CFUN=0/1`) if connection is lost.
* `nwy_demo_data_state_process(int profile_id, nwy_data_call_state_e state)`: Evaluates IP status and reports to controller.
* `nwy_demo_network_monitor_cb()`: Periodic check signal trigger.
* `nwy_demo_network_monitor_timer()` / `nwy_demo_data_call_monitor_timer()`: System timers setup.
* `nwy_network_monitor_func(void *param)`: Thread entry. Loops on events like timers and data status notifications.
### 4. nwy_demo_data.c
* **Purpose**: Manages network data connection (PDP) dialing.
* **Functions**:
* `nwy_demo_data_call_cb(int profile_idx, nwy_data_call_state_e ind_state)`: Triggers on connection state changes and updates local tables.
* `nwy_demo_call_info_get(int profile_idx, nwy_data_callinfo_t *info)`: Obtains and logs network IP and DNS.
* `nwy_demo_data_call_clear()`: Stops active dials.
* `nwy_demo_data_call_start()`: Configures APN options, registers state callbacks, and starts dialing profile 1.
### 5. nwy_demo_tcp.c
* **Purpose**: Establishes TCP connections and socket data transfers.
* **Functions**:
* `nwy_tcp_demo_recv(int fd, char *buf, int len, int64 timeout_s)`: Selects and reads data packets on a socket.
* `nwy_tcp_demo_data_recv_func(void *param)`: Task loop reading incoming data from socket descriptors.
* `nwy_tcp_cli_demo_setup(char *url, int port)`: Resolves host DNS, opens TCP sockets, and connects.
* `nwy_tcp_cli_demo_main(void)`: Setup the client socket and send test strings.
### 6. nwy_demo_utility.c
* **Purpose**: Common output utilities.
* **Functions**:
* `nwy_demo_uart_echo(char *fmt, ...)`: Thread-safe, mutex-protected formatted console log transmitter.
### 7. nwy_demo_vir_at.c
* **Purpose**: Interacts with the cellular modem core using virtual AT commands without physical UART ports.
* **Functions**:
* `nwy_vir_at_test_init()`: Configures mutexes and virtual AT parameters.
* `nwy_vir_at_send(char *at_command, char *ok_fmt, char *err_fmt, char *resp, int len)`: Wraps, signs, locks, and writes AT strings, capturing modem responses.
